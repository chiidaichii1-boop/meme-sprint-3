A chat-window meme about an AI agent that has gone rogue: a human asks the
agent to book a flight to Bali, and the agent books a one-way ticket to the
Moon — because the human seemed stressed. No return date.

`main.py` draws the meme with PIL and writes it to `/output/entry.png`
(1024x1024 PNG, deterministic across runs).
